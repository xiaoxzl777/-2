样稿：
  • 导航多一个「我的简历」（新的投递 / 我的投递 / 我的简历）。手机上照样三个都显示，logo 只留图标（现在就是这样腾地方的）。
  • 两个方案都改了三处：按钮归到一处；「用它投递 →」做成实心主按钮（最常用），「看原文」次之，「删除」只是淡色文字；解析失败的不再摆两个点不了的按钮。
  • 方案 A：和「我的投递」一样一行一份，三个按钮都在右边；底部横着列最近投的 3 个岗位。份数多的时候好扫。
  • 方案 B：两列卡片，最近投递竖着列（一行一个岗位，分数和结论靠右，好对比），按钮压在卡片底部。一般人只有一两份简历，两列更饱满；手机上变一列。
  • 「看原文」打开右侧抽屉看系统读出来的纸面（不画标注）；「删除」原地确认，和工作台里的删除一样；「用它投递 →」回工作台，这份简历已经选好，从选方向开始。
  • 点「选择文件」上传后，新的那份排在最上面、显示「解析中」，几秒后变成「已解析」（样稿里点一下就能看到）。不改后端。
