      样稿说明（这一块不进正式页面）
      • 这一版改了什么：① 手感换成和用户端一套：同一条导航（滚动后变毛玻璃）、跟着鼠标的光晕、磁吸的圆角按钮、会滑的分段切换、大标题逐行升起；卡片和表格一张接一张进场，数字会滚，柱子会长出来，鼠标停上去有回应。② 模型设置里多了检索模型：向量模型和重排模型都能换。③「添加一家」直接列出能选的几家，不用点开才知道。
      • 谁能看：只有 admin 账号。admin 登录后直接到管理端，不显示求职用的三个页面；普通用户打开这个地址会被送回工作台。
      • 模型用量：右上角选今天 / 近 7 天 / 近 30 天 / 全部；点图上任意一根柱子，四个数和两张表就只算那一天，再点一次（或点「看回…」）回到整段。只算用户操作产生的调用；花费是按单价和 token 数算的估算值。
      • 模型设置：保存、换 Key、切换之前都会先试一次连不连得上，连不上不让存。余额只有 DeepSeek 查得到。
      • 试试失败的样子：在任何一个填 Key 的地方填 bad 开头的内容，测试会报「密钥无效」。
      • 这里的用户、供应商和数字都是示例；右上角头像里可以切三套配色。
